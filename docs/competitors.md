# 경쟁 앱 분석 (2026-09-16)

앱스토어 페이지와 검색으로 확인한 것만 적는다. 직접 설치해 써본 것은 아니다.

## 어디에도 없는 것 (우리 자리)

1. **말로 하는 기도문.** 기도 앱은 전부 타이핑 기반. 음성으로 기도를 남기고 다시 듣는 앱은 검색 범위에서 못 찾았다.
2. **기도와 성경이 한 앱에서, 화면 세 개.** 성경 앱은 기능이 수십 개고, 기도 앱은 성경이 없다. 어르신은 두 앱을 오가지 못한다.
3. **광고 없음, 로그인 없음.** 경쟁 앱은 무료 대신 광고를 넣거나(바이블 애플·큰 글씨 성경), 로그인·인앱결제를 요구(갓피플). 어르신에게 광고 배너는 잘못 누르는 함정이다.
4. **성경 지도(3단계).** 위 어느 앱도 지도가 주요 기능이 아니다.

## 우리가 뒤지는 것

- **개역개정이 없다.** 경쟁 앱은 전부 개역개정이 기본. 부모님 교회가 개역개정을 쓰면 본문이 다르게 느껴질 수 있다. 개역한글은 60~70대가 자란 역본이라 괜찮을 가능성이 높지만 **부모님께 직접 확인해야 한다.** 개역개정을 넣으려면 대한성서공회 허가·사용료가 필요하다.
- **낭독 음원 품질.** 갓피플·바이블 애플은 성우 녹음. 우리는 기기 합성음. 아이패드 한국어 음성 품질을 직접 들어봐야 한다.
- **찬송가 없음.** 어르신 요청이 나올 수 있는 항목. 새찬송가는 저작권 있음(한국찬송가공회). 통일찬송가(1983) 이전 곡 중 저작권 만료된 것만 가능 — 확인 안 함.

## 결론

방향은 맞다. "적게, 크게, 말로"가 차별점이고, 기능을 더하는 쪽으로 가면 바이블 애플과 같은 자리에서 진다.
다음에 추가할 것은 새 기능이 아니라 (1) 음성 기도문 품질, (2) 낭독 품질, (3) 부모님 실사용 반응이다.
