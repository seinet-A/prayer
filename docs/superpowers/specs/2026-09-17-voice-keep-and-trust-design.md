# 내 목소리 보관 + 신뢰 3종 설계

작성: 2026-09-17. 성택님 선택: 아이디어 1번(내 목소리 녹음 보관), 3번(지우기 되돌리기, 첫 화면 안내, 소리 신호).

## 1. 내 목소리 녹음 보관

### 원칙
- **인식이 우선, 녹음은 덤.** 녹음 시작·저장이 실패해도 기도문(글)은 반드시 저장된다. 녹음 실패는 조용히 넘어간다.
- **말한 그대로.** "빼줘" 같은 명령도 녹음에 그대로 남는다. 녹음은 편집하지 않는다.
- 비용 0, 서버 없음. 기기 안에만.

### 동작
- 「말하기」 → 인식 시작 → 인식이 '듣는 중'이 되면 MediaRecorder로 녹음 시작(마이크 권한은 인식이 이미 받았으므로 추가로 안 묻는 것이 보통. 확인 안 함).
- 인식이 멈출 때마다(그만·됐어요·빼줘·잠시 멈춤) 녹음도 멈춰 조각(Blob) 하나로 보관. 「이어서 말하기」면 새 조각. 조각들을 순서대로 이어 들려준다(파일 합치기는 안 한다).
- 「저장」 때 조각들을 IndexedDB(`prayer-audio` / `parts`, 키 `기도ID:번호`)에 넣고, 기도문에 `audioParts: n`을 적는다. 조각 저장이 실패하면 `audioParts: 0`.
- 기도문 보기: `audioParts > 0`이면 「내 목소리로 듣기」 버튼(누르면 「멈춤」). 보기 화면을 열 때 조각을 미리 읽어 두어, 버튼 누름(사용자 동작) 안에서 바로 재생한다(iOS 자동재생 제한 대비).
- 기도 삭제 시 조각도 삭제(되돌리기 시간 지난 뒤).
- 키보드로 적은 기도는 녹음 없음. 전체 내보내기(JSON)에 녹음은 포함하지 않는다(용량). 나중에 「녹음 공유」로.

### 아이패드에서 확인할 것
- 인식과 녹음이 동시에 되는가(가장 큰 미지수). 안 되면: 녹음을 포기하거나, 인식 대신 녹음+클라우드 인식으로 가는 선택이 생긴다. 이 결정은 성택님.
- 조각 이어 듣기가 끊김 없이 되는가. 앱 껐다 켜도 남는가. 용량(분당 약 1MB, 추측).

## 2. 지우기 되돌리기
- 「네, 지워요」 → 홈으로 → 위에 "지웠어요 「되살리기」" 줄이 6초 동안. 누르면 원래 자리(날짜순)로 복구.
- 6초 지나면 줄이 사라지고 그때 녹음 조각을 지운다. 그 전엔 조각을 지우지 않는다.
- `store.js`에 `restore(store, prayer)` (넣고 createdAt 내림차순 정렬).

## 3. 첫 화면 안내
- 처음 한 번만(`localStorage.introSeen`). 큰 글씨 세 줄 + 「알겠어요」.
  - 말하기 버튼을 누르고 기도하세요.
  - 다 하시면 "됐어요"라고 말하세요.
  - 잘못 말한 줄은 "3번 빼줘"라고 하세요.
- 설정에 「안내 다시 보기」.

## 4. 소리 신호
- 듣기 시작할 때 짧은 높은 소리(880Hz, 0.12초), 멈출 때 낮은 소리(660Hz). Web Audio, 파일 없음.
- AudioContext는 「말하기」 누름(사용자 동작) 안에서 만든다(iOS 제한).
- 아이패드가 자체 효과음을 내서 겹치면 설정에서 끌 수 있게 한다(`localStorage.beep = 'off'`). 처음엔 켬.

## 5. 파일
- `audio.js`(새): 녹음 시작/멈춤, 조각 저장/읽기/삭제, 이어 재생, 삐 소리.
- `store.js`: `setAudio(store, id, n)`, `restore(store, prayer)`.
- `app.js`, `index.html`, `style.css`, `sw.js`(캐시 v6, audio.js 추가).
