# 어르신용 기독교 앱 — 2단계 「성경 읽기·듣기」 설계

작성: 2026-09-16. 1단계 설계(`2026-09-16-prayer-voice-design.md`)의 기술·UX 규칙을 그대로 따른다.

## 1. 범위

- 개역한글판(1961, 퍼블릭 도메인) 단일 역본. 책 → 장 → 본문을 큰 글씨로 보고, 읽어주기로 듣는다.
- 홈에 「이어서 읽기」(마지막 위치)와 「성경 찾기」(책·장 고르기) 둘 다 둔다. 부모님 반응 보고 조정.
- 뺀 것: 검색, 북마크, 메모, 다른 역본, 성경 지도(3단계), 절 단위 공유.

## 2. 데이터

### 2.1 출처
- `jsonpassion/pilsa-content`의 `content/bible/krv.json`(2026-09-14판) + `books.json`. 원본은 위키문헌 기반 Zefania `SF_2022-09-19_KOR_KORRV`. 저작권 만료(대한성서공회 공식 안내 확인). 본문은 수정하지 않는다.
- 검사 결과(2026-09-16): 66권, 31,084절, 순서 정상. **빠진 절 19개**(원본 누락: ISA.30.2, ISA.48.2, JER.21.2, EZK.24.5, PSA.72.20, MAT.18.11, MRK.9.44, MRK.9.46, MRK.11.26, MRK.15.28, LUK.17.36, LUK.23.17, ACT.8.37, ACT.15.26, ACT.15.34, ACT.28.29, ROM.9.2, ROM.16.24, 2CO.13.14). 인쇄본을 보고 나중에 채운다. 앱에서는 절 번호 뒤에 "(본문 준비 중)"으로 표시.
- 시편 표제 116개(`titles`, 예: PSA.3 → "다윗이 그 아들 압살롬을 피할 때에 지은 시")는 1절 앞에 작은 글씨로 보여준다.

### 2.2 앱 안의 형태
- `bible/index.json`: `[{ id:'GEN', ko:'창세기', chapters:50, ot:true }, ...]` 66개.
- `bible/GEN.json` … 66개 파일: `{ chapters: [ [절1, 절2, ...], ... ], titles: { "3": "다윗이 ..." } }`. 장은 1부터, 절 배열 인덱스 0이 1절. 빠진 절은 `null`.
- 변환 스크립트 `tools/build_bible.py`(표준 라이브러리만): 원본 두 JSON을 받아 위 파일들을 만든다. 만들면서 절 수·장 수·빠진 절 목록을 출력해 위 검사 결과와 맞는지 대조.
- 원본 두 파일은 `tools/source/`에 그대로 보관(출처·검증 문자열 포함).
- 전체 약 5MB. **앱 설치(서비스워커 install)와 분리**해서 받는다: 서비스워커는 `bible/` 요청을 캐시 우선(캐시 이름 `bible-v1`, 성공 응답만 저장)으로 처리하고, 앱은 시작할 때와 설정의 「성경 내려받기」 버튼에서 66개 파일을 차례로 fetch해 캐시를 채운다. 설정 화면에 "오프라인 준비 66/66"을 표시. 설치가 본문 다운로드 실패에 묶이지 않는다(모서리 검토 4·6·8).
- 절 참조는 `책ID.장.절`(예: `JHN.3.16`)을 고정 기준으로 쓴다. 3단계 지도는 별도 "절 범위 ↔ 장소" 자료로 연결한다(검토 13).

### 2.3 읽던 자리
- localStorage 키 `bibleLast`: `{ book:'JHN', chapter:3, verse:5 }`. 장을 열 때 book·chapter 갱신(verse는 1). 읽어주기 중 절이 바뀔 때, 절을 눌렀을 때, 멈췄을 때 verse 갱신. 없으면 홈의 「이어서 읽기」가 「창세기 1장부터」로 표시.
- 본문을 열면 저장된 verse로 스크롤. 「읽어주기」는 저장된 verse부터 시작(검토 1).

## 3. 화면

### 3.1 홈 (기존 화면 수정)
- 위에서부터 큰 버튼 세 개: 「기도하기」, 「이어서 읽기 — 요한복음 3장」, 「성경 찾기」.
- 그 아래 기존 지난 기도 목록.

### 3.2 책 고르기
- 「뒤로」. 「구약」「신약」 두 묶음 제목 아래 책 이름 버튼(2열 격자, 버튼 높이 80px 이상). 39 + 27개.
- 누르면 장 고르기.

### 3.3 장 고르기
- 「뒤로」, 제목 = 책 이름. 숫자 버튼 격자(4열). 시편은 150개라 스크롤.
- 누르면 본문.

### 3.4 본문
- 위: 「뒤로」(장 고르기로), 제목 = "요한복음 3장".
- 본문: 절마다 한 줄 이상. 절 번호는 작고 흐리게, 본문은 큰 글씨(설정의 글자 크기 따름). 시편 표제는 1절 위에 작은 글씨. 빠진 절은 "11 (본문 준비 중)".
- 아래 고정 줄: 「이전 장」 「읽어주기」 「다음 장」. 첫 장이면 「이전 장」은 앞 책 마지막 장으로, 마지막 장이면 「다음 장」은 다음 책 1장으로. 창세기 1장 이전·요한계시록 22장 다음은 버튼 비활성.
- 읽어주기: 저장된 절부터 장 끝까지 절 단위로 이어서 읽는다. 읽는 절을 연한 노란 배경으로 표시하고 화면에 보이게 스크롤. 사용자가 손으로 스크롤하면 따라가기를 멈추고, 「읽어주기」나 절을 다시 누르면 재개(검토 2). 누르면 「멈춤」, 멈춘 절이 저장되어 다음 「읽어주기」는 거기서부터. 절을 손가락으로 누르면 그 절부터 읽기 시작(읽는 중이면 그 절로 건너뜀). 장 끝까지 읽으면 멈추고 버튼은 「읽어주기」로.
- 절 번호는 본문 글자의 0.7배(보통 크기에서 약 20px), 회색. 하단 고정 줄이 본문 마지막 절을 가리지 않도록 본문 아래 여백을 버튼 줄 높이만큼 둔다(검토 3).
- 화면을 나가면 읽기 중단(1단계와 같은 규칙).

## 4. 기술

- 파일 추가: `bible.js`(본문 불러오기·앞뒤 장 계산·읽던 자리, 순수 함수 위주), `bible-ui.js`(세 화면), `tools/build_bible.py`, `bible/*.json`.
- `app.js`는 홈 버튼 세 개와 화면 전환만 담당. 화면 전환 `show()`는 `bible-ui.js`에서도 쓰므로 `app.js`에서 export하거나 작은 `ui.js`로 뺀다.
- `speech.js`에 `speakList(texts, startIndex, { onIndex, onDone })` 추가. 절마다 utterance 하나, **정상 종료(onend)일 때만** 다음 절로 이어가고, onerror·취소는 끝낸다. 실행마다 토큰을 두어 이전 실행의 늦은 콜백은 무시(검토 10). `stopSpeaking()`은 기존 것.
- `sw.js`: 앱 껍데기 캐시 이름 `prayer-v2`, `FILES`에 `bible.js`·`bible-ui.js`·`ui.js`·`bible/index.json` 추가(검토 5). `bible/*.json`은 별도 캐시 `bible-v1`에 캐시 우선, `r.ok`인 응답만 저장(검토 6). 껍데기도 `r.ok`일 때만 저장.
- 본문 불러오기: `fetch('bible/JHN.json')`. 실패(오프라인 + 캐시 없음)하면 "성경 본문을 불러오지 못했어요. 인터넷을 켜고 다시 열어 주세요".
- 앱·본문 버전이 섞일 위험은 남는다. 본문은 내용이 바뀌지 않는 한 캐시 이름을 올리지 않는다(검토 7, 감수).

## 5. 검증

- `test_bible.js`(node): 앞뒤 장 계산(창세기 1 이전 없음, 창세기 50 → 출애굽기 1, 말라기 4 → 마태 1, 계시록 22 다음 없음), 읽던 자리 저장·복원, 홈 버튼 문구.
- `tools/build_bible.py` 실행 결과: 66파일, 절 합계 31,084, 빠진 절 19개 목록이 2.1과 일치.
- PC 브라우저: 홈 → 성경 찾기 → 요한복음 → 3장 → 본문 → 읽어주기 하이라이트·멈춤 → 절 눌러 그 절부터 → 이전/다음 장 → 앱 다시 열면 「이어서 읽기 — 요한복음 4장」. 서버 끄고 열어 오프라인 확인.
- 아이패드 체크리스트에 항목 추가: **홈화면 앱 안에서** 성경 내려받기 66/66 확인 후 비행기 모드로 본문 열기·읽어주기(음성이 기기 내장인지), 이어 읽기 중 화면 잠금→복귀, 절 누르면 즉시 그 절로(검토 9·11·12). 사파리 탭에서 받은 본문은 홈화면 앱으로 복사되지 않는다.
