# 말로 끝내기·빼기 설계 (자비스 2·3단계)

작성: 2026-09-17. 성택님 결정: 5단계 중 3단계까지(다듬기 → 끝내는 말 → 빼기). 바꾸기·되묻기는 부모님 반응 보고.

## 1. 원칙
- **AI 없이, 기기 안에서, 공짜로.** 끝내는 말과 빼기는 규칙(정규식·낱말 겹침)으로 알아듣는다. 서버·비용 없음. 규칙으로 안 되는 경우("바꾸기", 후보가 여럿)는 다음 단계에서 AI로.
- **확신 없으면 기도로.** 고치는 말인지 애매하면 기도 내용으로 붙인다. 잘못 붙은 건 지우면 되지만 잘못 지운 건 다시 말해야 한다.
- **지우기 전에 보여주고 묻는다.** 뺄 부분을 빨간 줄로 보여주고 「네, 빼주세요」「아니에요」.
- **엔진과 쓰임새 분리.** 규칙은 `commands.js`에 순수 함수로. 기도 화면(`app.js`)은 그걸 부를 뿐. 나중에 편지·일기에도 그대로 쓴다.

## 2. 글의 단위: 구절
- 음성 인식 결과는 부호가 없어서 "문장"이 없다. 대신 **구절**로 나눈다: 기도에서 흔한 맺음말(…시고, …옵고, …시며, …니다, …소서, …세요, …아멘, …게요/께요)로 끝나는 낱말 뒤에서 끊는다.
- 녹음 화면은 구절을 한 줄씩 보여준다. 저장할 때도 줄바꿈으로 남긴다(다듬기가 나중에 부호를 넣는다).
- 확인 화면의 글상자에서 고치면 줄 단위가 구절이다.

## 3. 알아듣는 말
| 종류 | 예 | 동작 |
|---|---|---|
| 끝내기(그 자체) | 됐어, 됐어요, 이제 끝, 그만, 다 했어요 | 그 말은 안 넣고 끝냄 → 확인 화면 |
| 끝내기(아멘) | …기도합니다 아멘 | 아멘까지 넣고 끝냄 |
| 빼기(마지막) | 방금 거 빼줘, 여기서부터 다시, 다시 할게, 마지막 거 지워줘 | 마지막 구절을 뺄지 물음 |
| 빼기(내용) | 아까 무릎 얘기 빼줘, 손주 시험 얘기한 거 지워줘 | 낱말이 가장 많이 겹치는 구절을 뺄지 물음. 같으면 최근 것 |
| 애매 | 이 병을 빼주세요 (가리키는 말 없음) | 기도로 붙임 |

빼기로 인식하려면 **빼는 동사**(빼줘·지워줘·없애줘·다시 할게·여기서부터 다시)와 **가리키는 말**(아까·방금·그·얘기·말한·한 거·부분·마지막·여기서) 둘 다 있어야 한다.

## 4. 흐름 (녹음 화면)
- 인식기가 확정 구간(final)을 줄 때마다 `ingest(구절들, 구간)` → 새 구절 목록 + 동작(없음/끝/빼기).
- 끝: 인식 멈추고 확인 화면.
- 빼기: 인식 멈추고, 대상 구절 빨간 줄, "이 부분을 뺄까요?" 「네, 빼주세요」「아니에요」. 답하면 「이어서 말하기」「다 했어요」 상태(잠시 멈춤과 같음). 대상을 못 찾으면 "어느 부분인지 못 찾았어요" + 같은 두 버튼.
- 인식기 재시작 시 이전 결과가 다시 오는 iOS 버그 대비: 이미 처리한 final 개수를 세어 새것만 받는다(`speech.js`).

## 5. 검증
- `test_commands.js`: 구절 나누기, 끝내기 변형, 아멘, 빼기(마지막/내용/동률/못 찾음), 기도로 붙는 경우("이 병을 빼주세요").
- `test_speech.js`: final 재전달 시 중복 안 됨.
- 브라우저: 키보드 경로로 구절 줄바꿈 저장 확인. 음성 경로는 아이패드에서: "됐어"로 끝나기, "아까 ○○ 얘기 빼줘" → 빨간 줄 → 네/아니요.
