# 「다듬기」 설계 (기도문 AI 정리)

작성: 2026-09-16. 1단계 설계의 "다듬기 자리"를 채운다.

## 1. 결정 사항 (성택님과 합의)
- 음성인식은 아이패드 내장(무료)으로 충분함을 실기기에서 확인. 클라우드 음성인식은 안 쓴다.
- 내장 인식의 약점(문장 부호 없음, 군말)을 Claude가 정리한다. **사용자가 「다듬기」를 누를 때만** 호출. 비용은 호출 때만 발생.
- 원문은 불변. 다듬은 글은 옆에 저장하고 「원문으로」/「다듬은 글로」로 보여주는 쪽만 바꾼다(데이터 구조는 이미 있음: `refined`, `refinedAt`, `showing`).
- 말로 고치기("여기서부터 다시")는 다음 단계.

## 2. 구조
```
아이패드 앱 ──POST {text}──▶ Cloudflare Worker ──Messages API──▶ Claude
          ◀── {refined} ───              (API 키는 여기만)
```
- Worker는 성택님 Cloudflare 계정에 대시보드에서 코드 붙여넣기로 배포(빌드 도구 없음). 파일: `worker/refine.js`.
- API 키는 Worker의 비밀 변수 `ANTHROPIC_API_KEY`에만 둔다. 저장소·앱에는 절대 안 둔다.
- 모델: `claude-opus-5`, `output_config.effort: "low"`(정리 작업이라 깊은 사고 불필요). 회당 약 20원 추정(입력 600·출력 400토큰 기준). 더 싸게 하려면 `MODEL` 한 줄을 `claude-haiku-4-5`로 바꾼다(회당 약 3원).
- SDK 대신 fetch로 직접 호출: 대시보드 붙여넣기 방식이라 npm 패키지를 못 쓴다.

## 3. Worker 규칙
- `POST` + JSON `{ text }`만 받는다. `OPTIONS`는 CORS 응답.
- `Origin`이 허용 목록(`https://seinet-a.github.io`, `http://localhost:8000`)이 아니면 403. (Origin은 위조 가능하므로 보조 수단. 진짜 방어는 아래 지출 한도.)
- `text`는 4,000자 이하. 넘으면 413. 비어 있으면 400.
- Claude 응답이 `stop_reason: "refusal"`이거나 텍스트가 없으면 502.
- 성공: `{ refined }`.
- **지출 한도**: Anthropic 콘솔에서 월 한도(예: 5달러)를 성택님이 직접 설정. 공개 엔드포인트가 남용되어도 그 이상 못 나간다.

## 4. 시스템 프롬프트 (Worker 안에 상수)
내용·순서·이름·부탁을 바꾸지 않는다. 새 내용·성경 구절·미사여구 금지. 문장 나누고 부호 넣기. 군말·반복·기도 아닌 말 제거. 인식 오류는 문맥으로 바로잡되 불확실하면 그대로. 말투 유지. 「아멘」 없으면 안 붙임. 본문만 출력.

## 5. 앱 변경
- 기도문 보기 화면: 「다듬기」 버튼(아직 안 다듬었을 때), 다듬은 뒤에는 「원문으로」/「다듬은 글로」 토글 버튼.
- 누르면 "다듬는 중…" → 결과를 저장(`refined`, `refinedAt`, `showing='refined'`) → 화면 갱신.
- 인터넷 없음: "인터넷이 필요해요". 서버 오류: "지금은 다듬을 수 없어요. 나중에 다시 해주세요". 원문은 어떤 경우에도 그대로.
- Worker 주소는 `app.js`의 `REFINE_URL` 상수. 비어 있으면 「다듬기」 버튼을 숨긴다(배포 전 상태).
- `store.js`에 `setRefined(store, id, refined, now)` 추가.

## 6. 검증
- `test_worker.js`(node, 가짜 fetch): OPTIONS/405/403/400/413/502/성공/refusal, 업스트림에 보내는 body(model·text).
- `test_store.js`에 setRefined 검사 추가.
- PC 브라우저: REFINE_URL 비었을 때 버튼 숨김. Worker 배포 후: 다듬기 → 결과 → 원문으로 → 다듬은 글로.
- 아이패드: 실제 기도로 다듬기 결과가 "내용은 그대로, 부호만" 인지 성택님이 판단.

## 7. 모서리 검토 반영 (2026-09-17)
- 반영: 요청 시작 시 기도 ID 고정(다른 기도에 결과 저장되던 버그), `stop_reason: max_tokens`는 실패 처리, Content-Length 20KB 상한, 앱 fetch 30초 시간 제한, 다른 Origin에는 CORS 헤더 미제공, Haiku 전환 시 `output_config` 자동 제거, 프롬프트의 삭제·교정 범위 축소(간절한 반복·낯선 이름 보존).
- 보류: Cloudflare Turnstile(봇 검증). 어르신 화면에 검증 단계가 늘어나므로 남용이 실제로 관찰될 때 넣는다. 지출 한도가 1차 방어.
- 비용 상한: 회당 출력 4,000토큰 = Opus 5 기준 최대 약 0.1달러. 평균은 그보다 훨씬 낮다.
