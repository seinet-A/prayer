# 어르신용 기독교 앱 — 1단계 「말하면 기도문」 설계

작성: 2026-09-16

## 1. 배경과 범위

- 대상: 60~70대 어르신(첫 사용자는 성택님 부모님). 아이패드 사파리, 홈화면에 추가한 웹앱(PWA).
- 개발 환경: Windows PC, Mac 없음. 그래서 네이티브 대신 PWA. 앱스토어 출시는 나중(그때 클라우드 Mac 대여).
- 전체 로드맵: 1) 말하면 기도문 → 2) 성경 읽기·듣기(개역한글판 단일, 아래 5절) → 3) 성경 지도(읽는 장과 연결).
- 이 문서는 1)만 다룬다.

## 2. 요구사항

1. 큰 버튼을 눌러 말하면 글로 바뀐다. 저장 전에 글을 고치거나 이어서 말할 수 있다. 저장한 글이 **원문**이다.
2. 원문은 한 번 저장되면 바뀌지 않는다. 나중에 AI 「다듬기」가 붙어도 원문 옆에 따로 두고, 「원문으로」/「다듬은 글로」는 보여주는 쪽만 바꾼다. (1단계는 다듬기 미구현, 구조만 준비.)
3. 저장은 아이패드 안에만. 서버·로그인 없음. 나중에 서버로 옮기기 쉬운 데이터 구조.
4. 저장된 기도문 목록을 보고, 열어서 읽고, 읽어주기(TTS)로 듣는다. 읽어주기는 멈출 수 있고 화면을 나가면 자동 멈춤.
5. 공유(iOS 공유 시트)로 텍스트를 메모·카카오톡 등에 보낼 수 있다. 전체 기도문을 파일 하나(JSON)로 내보낼 수 있다. 가져오기는 서버 단계로 미룸.
6. 삭제는 한 번 더 묻는다.
7. 음성이 어떤 이유로든 안 되면(미지원, 권한 거절, 시작 실패, Siri 꺼짐) 키보드 입력 칸으로 넘어간다. 아이패드 키보드의 마이크 받아쓰기가 두 번째 음성 경로가 된다.
8. 저장 실패 시 글을 잃지 않고 다시 시도할 수 있다.

## 3. 화면 (3개)

### 3.1 홈
- 위: 큰 버튼 「기도하기」.
- 아래: 지난 기도 목록. 각 줄 = 날짜(예: 9월 16일 저녁) + 본문 첫 줄. 누르면 3.3.
- 오른쪽 위 작은 「설정」: 전체 내보내기(JSON), 글자 크기(보통/크게/아주 크게).

### 3.2 녹음
- 왼쪽 위 「뒤로」. 가운데 큰 원형 마이크 버튼. 아래에 인식된 글이 쌓이는 큰 글씨 영역.
- 상태와 화면:
  | 상태 | 화면 |
  |---|---|
  | 대기 | 버튼 회색, "버튼을 누르고 말씀하세요" |
  | 권한 요청 중 | "마이크 사용을 허락해 주세요" |
  | 듣는 중 | 버튼 빨강, "듣고 있어요", 글이 실시간으로 쌓임 |
  | 마무리 중 | "정리하고 있어요" (stop() 후 마지막 결과 수신까지) |
  | 잠시 멈춤 (기기가 스스로 멈춘 경우) | 글 유지, "잠시 멈췄어요" + 「이어서 말하기」 「다 했어요」 |
  | 실패 (권한 거절·시작 실패·미지원) | 이유 한 줄 + 키보드 입력 칸으로 전환 |
- 「다 했어요」 → 확인 화면: 글 전체가 편집 가능한 큰 칸에 보임. 버튼 「저장」 「이어서 말하기」 「다시 하기」. 저장한 글이 원문.

### 3.3 기도문 보기
- 왼쪽 위 「뒤로」. 본문 큰 글씨(현재 보여주는 쪽).
- 버튼: 「읽어주기」(누르면 「멈춤」으로 바뀜) 「공유」 「지우기」.
- 2단계에서 「다듬기」 「원문으로/다듬은 글로」 추가 자리.

### 3.4 어르신 UX 규칙
- 본문 28px 이상(설정으로 32/40), 버튼 높이 80px 이상, 흰 바탕 검은 글씨, 한 화면 한 행동.
- 밀기·길게 누르기 제스처 없음. 「뒤로」는 항상 왼쪽 위 같은 자리.
- 삭제는 2단계 확인. 되돌릴 수 없는 행동은 이것뿐.
- 화면 회전은 세로 고정 권장(manifest orientation: portrait).

## 4. 데이터

```
Prayer = {
  id: string,           // crypto.randomUUID(), 기기에서 생성
  createdAt: string,    // ISO 8601
  original: string,     // 불변
  refined: string|null, // 1단계에서는 항상 null
  refinedAt: string|null,
  showing: 'original'|'refined',
  source: 'speech'|'typed'
}
Store = { version: 1, prayers: Prayer[] }   // 최신이 앞
```
- localStorage 키 `prayers`에 JSON 문자열 하나. `navigator.storage.persist()` 요청.
- 서버 이전 시 Store를 그대로 업로드. id가 UUID라 충돌 없음. 수정 충돌·삭제 전파는 동기화가 확정될 때 설계.
- 홈화면 앱과 사파리 탭은 저장소가 분리된다(WebKit 문서 확인). 처음부터 홈화면에 추가해서 쓰도록 안내하고, 사파리 탭에서 쓴 기도는 옮기지 않는다.

## 5. 성경 본문 (2단계 대비, 결정 사항만)

- 한글 성경 중 저작권 만료는 「개역한글판」(1961, 2012년 만료) 하나(대한성서공회 공식 안내 확인). 개역개정·새번역·공동번역·새한글성경(대한성서공회), 쉬운성경(아가페), 현대인의 성경은 허가·비용 필요 → 배제.
- 2단계는 개역한글판 단일. 본문 데이터는 기도문 저장소와 별도 파일/키로 둔다.

## 6. 기술

- 순수 HTML/CSS/JS, 빌드 없음, 외부 라이브러리 없음.
- 파일: `index.html`(화면 3개를 섹션으로, JS로 전환), `style.css`, `app.js`(화면·이벤트), `store.js`(저장 순수 함수), `speech.js`(음성→글, 글→음성), `manifest.webmanifest`, `sw.js`(오프라인 캐시), `icons/`.
- 음성→글: `webkitSpeechRecognition`, `lang='ko-KR'`, `continuous=false`로 두고 사용자가 누를 때만 시작(push-to-talk). 인스턴스 하나만 재사용. final 결과만 누적. `onend`가 사용자 조작 없이 오면 "잠시 멈춤" 상태.
- `speech.js`는 `start(onText, onState)`, `stop()` 두 함수만 노출. 나중에 녹음+AI 음성인식으로 바꿔도 `app.js`는 그대로.
- 글→음성: `speechSynthesis`, `ko-KR` 음성 선택(`voiceschanged` 대응), rate 0.85. 한국어 음성 없으면 안내. 화면 전환 시 `cancel()`.
- 공유: `navigator.share({text})`. 미지원이면 클립보드 복사.
- 호스팅: HTTPS 필요(사파리 마이크 조건). GitHub Pages 또는 Cloudflare Pages. 올리기 전에 별도 승인.

## 7. 검증

- `store.js`: 추가·목록·삭제·showing 전환·JSON 내보내기를 node 테스트 하나(`test_store.js`)로 돌린다.
- PC 브라우저(Edge/Chrome)에서 화면 흐름 확인.
- 아이패드 체크리스트(성택님이 직접): 홈화면 추가 → 첫 녹음 → 잠시 멈춤 후 이어서 → 저장 → 다시 열기 → 읽어주기·멈춤 → 공유 → 지우기 → 앱 껐다 켜서 남아 있는지 → 권한 거절했을 때 키보드 칸 나오는지 → 비행기 모드에서 앱이 뜨는지.

## 8. 1단계에서 뺀 것
AI 다듬기, 서버 저장·로그인, 여러 기기 동기화, JSON 가져오기, 성경, 지도, 손글씨, 앱스토어.
