# 아이패드 확인 목록

앱 주소: https://seinet-a.github.io/prayer/

앱 주소를 사파리로 연 다음, **먼저 홈화면에 추가**하고(공유 버튼 → 홈 화면에 추가) 홈화면 아이콘으로 연다.
사파리 탭에서 쓴 기도는 홈화면 앱과 저장소가 달라 안 보인다.

| # | 할 일 | 기대 | 결과 |
|---|---|---|---|
| 1 | 홈화면 아이콘으로 열기 | 주소창 없이 전체 화면 | |
| 2 | 기도하기 → 말하기 → 허용 | 빨간 「그만」, "듣고 있어요", 글이 쌓임 | |
| 3 | 말하다 5초쯤 쉬기 | "잠시 멈췄어요", 글 남아 있음 | |
| 4 | 이어서 말하기 | 뒤에 붙음 | |
| 5 | 그만 → 확인 → 글자 하나 고치기 → 저장 | 홈 목록에 보임 | |
| 6 | 목록 눌러 열기 → 읽어주기 | 한국어 소리, 「멈춤」으로 멈춤 | |
| 7 | 읽는 중 뒤로 | 소리 멈춤 | |
| 8 | 공유 | 공유창 뜸(메모에 저장해 보기) | |
| 9 | 앱 완전히 끄고 다시 열기 | 기도 남아 있음 | |
| 10 | 비행기 모드로 열기 | 앱이 뜨고 목록 보임(음성은 안 될 수 있음) | |
| 11 | 설정 → 마이크 → 이 앱 거부 후 말하기 | "마이크를 쓸 수 없어요" + 키보드 칸 | |
| 12 | 키보드 칸의 마이크로 받아쓰기 | 글이 들어감 → 저장됨 | |
| 13 | 지우기 → 아니요 / 네 | 남음 / 사라짐 | |
| 14 | 설정 → 아주 크게 | 글자 커지고 유지됨 | |
| 15 | 설정 → 전체 내보내기 | 공유창에 json 파일 | |
| 16 | 설정 → 성경 내려받기 (홈화면 앱 안에서) | "오프라인 준비 66/66" | |
| 17 | 비행기 모드 → 성경 찾기 → 요한복음 3장 | 본문 보임 | |
| 18 | 절 하나 누르기 | 노랗게 표시됨 | |
| 19 | 앱 껐다 켜서 「이어서 읽기」 | 그 장, 표시한 절로 | |
| 21 | 기도하기 → 말하기 → 몇 마디 → "됐어요" | 말한 내용만 남고 확인 화면으로 | |
| 22 | 말하기 → "…기도합니다 아멘" | 아멘까지 들어가고 확인 화면으로 | |
| 23 | 말하기 → 서너 구절 → "아까 ○○ 얘기 빼줘" | 그 구절 빨간 줄 + 「네, 빼주세요」「아니에요」 | |
| 24 | 「네, 빼주세요」 → 이어서 말하기 | 빠진 채로 계속 | |
| 25 | "방금 거 빼줘" | 마지막 구절 빨간 줄 | |
| 26 | "이 병을 빼주세요" (기도) | 그대로 기도에 들어감 | |
| 27 | 녹음 화면에서 구절이 줄 단위로 보이는지 | …시고 / …니다 뒤에서 줄바꿈 | |
| 28 | 처음 열기(홈화면 앱 새로 추가하거나 설정 → 안내 다시 보기) | 큰 글씨 안내 3줄 → 「알겠어요」 | |
| 29 | 말하기 시작·끝 | "띵" 소리 두 가지. 아이패드 자체 소리와 겹치면 설정에서 끄기 | |
| 30 | 말로 기도 저장 → 열기 | 「내 목소리로 듣기」 버튼이 보이고, 누르면 내 목소리 | |
| 31 | 이어서 말하기로 두 번 나눠 말한 기도 | 두 조각이 이어서 들림 | |
| 32 | 녹음이 켜져도 인식이 계속 되는지 | 글이 계속 쌓임 (안 되면 알려주기: 제일 중요) | |
| 33 | 지우기 → 「되살리기」(6초 안) | 원래 자리로 돌아옴 | |
| 34 | 지우기 → 6초 기다림 | 되살리기 줄 사라짐 | |
| 35 | 앱 껐다 켜서 내 목소리 듣기 | 여전히 들림 | |
| 20 | 아주 크게 설정에서 본문 | 절 번호 읽힘, 마지막 절이 하단 버튼에 안 가림 | |

안 되는 항목은 번호와 화면 사진을 벼리에게.
